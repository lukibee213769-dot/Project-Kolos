# Kolos package manager

Package-manager and repository experiments. This component is a work in
progress and is **not included in the stable Kolos language/Python 1.0.1
distribution**. It has no separate release version.

The experimental bootable OS is versioned independently; its final planned
release is **Kolos OS v0.2.2**. See the [project README](../README.md) for the
supported release scope.
