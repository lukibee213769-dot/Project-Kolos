# Kolos runtimes

Python runtime and virtual-machine components for the Kolos language. They are
part of the stable **Kolos language/Python toolchain 1.0.1**; they do not have
a separate release number. The final planned experimental OS release is
**Kolos OS v0.2.2** and includes a bare-metal bytecode VM.

See the [project README](../README.md) for installation and usage.
