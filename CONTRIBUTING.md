# Contributing to Projekt Kolos

Thank you for wanting to contribute! This document describes the basic workflow.

1. Fork the repository and create feature branches.
2. Write tests for new functionality; run `python -m unittest discover -s tests -p "test_*.py" -v`.
3. Update or add documentation in `docs/`.
4. Open a pull request and describe the change and testing performed.

Maintainership and governance will be defined as the project grows.
