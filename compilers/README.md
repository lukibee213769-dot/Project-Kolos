# AXIOM compilers

Compiler front ends and back ends for AXIOM's AXIOM language. These components are
released as part of the stable **AXIOM language/Python toolchain 1.0.2**, not
as independently versioned packages. The experimental bootable OS release is
separate: **AXIOM OS v0.2.2**, the final planned OS prototype release.

See the [project README](../README.md) for setup and the supported release scope.
