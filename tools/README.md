# AXIOM developer tools

This directory contains developer tooling that is part of the AXIOM source
workspace. The stable language/Python toolchain release is **1.0.2**. The
final planned experimental bootable OS release is **AXIOM OS v0.2.2**; these
tools do not have an independent release version.

See the [project README](../README.md) for setup and the
[developer guide](../docs/DEVELOPERS.md) for workspace instructions.
