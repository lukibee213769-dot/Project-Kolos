# Kolos developer tools

This directory contains developer tooling that is part of the Kolos source
workspace. The stable language/Python toolchain release is **1.0.1**. The
final planned experimental bootable OS release is **Kolos OS v0.2.2**; these
tools do not have an independent release version.

See the [project README](../README.md) for setup and the
[developer guide](../docs/DEVELOPERS.md) for workspace instructions.
