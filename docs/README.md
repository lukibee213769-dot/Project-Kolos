# Kolos documentation

Project documentation, tutorials, and governance material.

## Release versions

- Stable Kolos language/Python toolchain: **1.0.1**.
- Experimental bootable Kolos OS: **v0.2.1**, maintained separately under
  [`kernel/os/`](../kernel/os/README.md).

Start with the [project README](../README.md) and
[developer guide](DEVELOPERS.md). The OS is a bootable prototype; storage,
userspace, and a persistent filesystem are not implemented.
