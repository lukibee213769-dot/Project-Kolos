# AXIOM documentation

Project documentation, tutorials, and governance material.

## Release versions

- Stable AXIOM language/Python toolchain: **1.0.2**.
- Final planned experimental bootable AXIOM OS release: **v0.2.2**, maintained separately under
  [`kernel/os/`](../kernel/os/README.md).

Start with the [project README](../README.md) and
[developer guide](DEVELOPERS.md). The OS is a bootable prototype; storage,
userspace, and a persistent filesystem are not implemented. See
[`PROJECT_STATUS.md`](../PROJECT_STATUS.md) for the final project status.
